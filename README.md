# ربات رزرو بیت‌الحسین (bh-bot)

ربات تلگرام رزرو اقامتگاه رایگان در **نجف** و **کربلا** — تقویم شمسی، اعتبارسنجی کد ملی، ظرفیت شبانه به تفکیک جنسیت و سه نقش ادمین.

## نصب روی سرور اوبونتو (تک‌خطی)

```bash
curl -fsSL https://raw.githubusercontent.com/For256256/Samanak/main/install.sh | sudo bash
```

اسکریپت به‌صورت تعاملی توکن ربات، آی‌دی ادمین‌ها و ظرفیت‌ها را می‌پرسد، سپس Node 20، وابستگی‌ها و سرویس systemd را نصب می‌کند.

پیش‌نیاز: Ubuntu 22.04/24.04، دسترسی root و اتصال به `api.telegram.org`.

## ساختار

| مسیر | توضیح |
|---|---|
| `src/index.js` | نقطه شروع ربات |
| `src/flow.js` | گفت‌وگوی رزرو و پنل ادمین |
| `src/db.js` | لایه SQLite (ظرفیت، تداخل، گزارش) |
| `src/keyboards.js` | تقویم شمسی و شمارنده‌ها |
| `src/config.js` | خواندن تنظیمات از `.env` |
| `deploy/bh-bot.service` | یونیت systemd |
| `scripts/selftest.js` | تست خودکار پیش از راه‌اندازی |

## قوانین رزرو

- یک کد ملی نمی‌تواند در تاریخ‌های هم‌پوشان دو رزرو داشته باشد (نجف و کربلا هم‌زمان ممنوع).
- ظرفیت هر شب به تفکیک آقا/خانم کنترل می‌شود.
- سقف شب اقامت، سقف روز جلوتر و سقف نفرات در `.env` قابل تنظیم است.

## نقش‌های ادمین

- **ادمین کل** — تایید هر دو شهر + گزارش و خروجی
- **ادمین نجف** / **ادمین کربلا** — فقط رزروهای شهر خودش

## نگهداری

```bash
journalctl -u bh-bot -f          # لاگ زنده
systemctl restart bh-bot         # ری‌استارت
nano /opt/bh-bot/.env            # تغییر تنظیمات (سپس ری‌استارت)
```

## اجرای محلی

```bash
cp .env.example .env   # مقادیر را پر کنید
npm install
npm run check          # تست
npm start
```
